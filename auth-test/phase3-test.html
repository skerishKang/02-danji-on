단지온 PHASE 3 통합 테스트

비밀번호와 JWT는 화면에 출력하지 않습니다. 신청 ID와 테스트용 가게명만 브라우저 sessionStorage에 임시 저장합니다.

로그인








  
1. user 7 — 신청자


  

    user 7 로그인 후 한 번 누릅니다.
    내 가게 신청 1건 + 승인용 제보 1건 + 거절용 제보 1건을 만듭니다.
  


  

  







  
2. user 1 — 관리자 1차 심사


  

    user 7 로그아웃 → user 1 로그인 후 누릅니다.
  


  

  







  
3. user 7 — 수정·재제출


  

    user 1 로그아웃 → user 7 로그인 후 누릅니다.
  


  

  







  
4. user 1 — 최종 보안검증


  

    user 7 로그아웃 → user 1 로그인 후 누릅니다.
    증빙 없는 점주 신청이 승인되지 않는지 확인합니다.
