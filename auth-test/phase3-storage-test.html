단지온 PHASE 3 Storage REAL E2E

비밀번호와 JWT는 화면에 출력하지 않습니다. 파일 내용은 테스트용 더미 바이트이며 개인정보를 포함하지 않습니다.

0. 실행 모드 (대상 Worker)

기본값은 LOCAL입니다. LOCAL은 Vite가 /local-api/...를 로컬 Worker (http://127.0.0.1:8787)로 중계합니다. PRODUCTION은 /prod-api/...를 실제 배포 Worker로 중계합니다. 둘 다 same-origin이라 브라우저 CORS 문제가 없습니다.

PRODUCTION 모드에서 파일 업로드·삭제·신청 생성·승인은 실제 Cloudflare Worker/R2에 테스트 데이터를 생성합니다. 아래 확인란을 켜지 않으면 모든 mutation 버튼이 차단됩니다. 읽기(목록·조회)는 차단되지 않습니다.

4. Storage 자동 테스트 실행

6. 승인 게이트 시도 (주의: 실제 심사 동작)


  

    이 버튼은 실제 관리자 승인 API를 호출합니다.
    proof가 있는 신청이면 실제로 가게가 발행(published)될 수 있습니다.
    proof가 없는 신청이면 409 OWNER_PROOF_REQUIRED로 차단됩니다.
    관리자(operator/admin) 계정으로 로그인한 상태에서만 동작합니다.
  


  

  







  
7. 최종 READ-ONLY 확인 (선택된 신청 + 발행 가게)


  

    읽기 전용입니다. GET만 호출하며 업로드·삭제·승인을 하지 않습니다.
    현재 로그인 세션(user 1 또는 user 7)을 그대로 사용합니다.
    2단계에 입력된 신청 ID를 읽어 그 신청과
    연결된 published_business_id 가게를 자동으로 확인합니다.
    PRODUCTION 확인란이 꺼져 있어도 동작합니다.
    민감정보(설명·연락처·파일 내용)는 표시하지 않습니다.
