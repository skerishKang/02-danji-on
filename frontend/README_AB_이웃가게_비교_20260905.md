# DanjiOn 이웃가게 A/B 비교안 (2026-09-05)

이 문서는 008 프론트엔드 최종 검토 중 **이웃가게/주민혜택 표현만** 비교하기 위한 안내입니다.

## A안 — 현재 008 정식안
- 웹 시작: `index.html`
- 앱 시작: `app.html`
- 이웃가게: 현재 008의 목록/상세 페이지 방식
- 주민혜택: 현재 008 방식
- 나머지 메뉴/회원가입/우리단지/내정보는 현재 008 기준

## B안 — 이웃가게 팝업·카드형 비교안
- 웹 시작: `index2.html`
- 앱 시작: `app2.html`
- **나머지 화면은 A안과 동일한 008 디자인을 사용**
- 이웃가게 관련 부분만 다음처럼 변경
  - 가게 상세를 사진 중심 팝업/모바일 시트로 표시
  - 저장 액션을 팝업 안에서 제공
  - 저장한 이웃가게를 사진 카드형으로 확인
  - 주민혜택을 카드형으로 표시
  - 혜택 보기를 누르면 쿠폰/혜택 상세 팝업 표시
- B안 지원 페이지
  - `01_이웃가게_발견_v2.html`
  - `03_주민혜택_쿠폰_v2.html`

## 판단 기준
1. 가게를 찾는 속도와 정보 이해가 쉬운가
2. 사진이 실제 가게/서비스를 신뢰하게 만드는가
3. 상세 페이지 이동보다 팝업이 덜 복잡한가
4. 저장·혜택·쿠폰 흐름이 자연스러운가
5. 모바일에서 사각형이 과도하게 쌓여 답답해 보이지 않는가

## 공통 수정
- 앱 홈 검색창 좌우 정렬/폭을 다시 고정함
- 내정보의 `저장한 이웃가게`, `받은 혜택`이 각각 올바른 화면으로 이동하도록 라우팅 수정함

최종 채택 후에는 A 또는 B 한쪽만 정식 프론트엔드 기준으로 승격하고 비교용 파일은 개발 기준에서 제외하면 됩니다.
