# 단지온 v7 반응형·접근성 검증

## 검증 폭

1440×1100, 1280×800, 1024×768, 768×1024, 430×932, 390×844, 360×800, 320×720.

## 판정 항목

- 전체 문서 `overflow-x`: 없음
- 모바일 첫 화면: 워드마크, 메뉴, 작업사진, 서비스 정의, 검색, CTA 확인
- 한국어 제목: `word-break: keep-all`, `overflow-wrap: normal`; 320px에서도 어절 중간 분리 없음
- 모바일 본문: 16px 이상
- 주요 버튼: 모바일 52px, 데스크톱 54px 이상
- 터치영역: 48px 이상
- 모바일 하단 메뉴: 홈·이웃가게·주민혜택·단지소식·내정보 5개
- 하단 메뉴와 본문: body 하단 padding으로 겹침 방지
- 서비스 가로 탐색: 버튼, 위치 표시, 키보드 좌우키 제공
- 모달: 열릴 때 첫 조작요소 포커스, Tab 순환, Escape 닫기
- 선택 상태: 색+그림자/문구/ARIA 병기
- `prefers-reduced-motion`: 애니메이션·전환·부드러운 스크롤 제거
- 자동 소리·스크롤 가로채기·자동 모바일 슬라이드: 없음

## 태블릿 재배치

820px 이하에서 히어로는 사진→정보면 순서로 세로 전환한다. 768px에서 사진 360px, 제목은 3개 줄 블록으로 유지하며 어절이 분리되지 않는다.
