# 단지온 v7 키아트 미구현 범위

키아트 승인 전에는 다음을 제품 기능으로 통합하지 않는다.

- 실제 회원가입·로그인·입주민 인증 서버
- 실제 주민·사업자 데이터베이스
- 영구 저장·찜·비교 동기화
- 실제 지도·거리·길찾기 API
- 전화·문자·카카오톡 문의 전달
- 별도 이웃가게 목록·상세 URL과 브라우저 라우팅
- 실제 후기 작성·검증·신고
- 단지생활 가이드 상세 글
- 파일 업로드·사진 검수·사업자 심사 워크플로
- 관리자·SEO 화면
- 지역·계절 랜딩 자동생성
- 분석·알림·결제

현재 모달과 목록은 키아트의 기능·상호작용 밀도를 검증하기 위한 프론트엔드 프로토타입이다.
