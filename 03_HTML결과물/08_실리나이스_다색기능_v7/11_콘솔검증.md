# 단지온 v7 콘솔 검증

- Vanilla JavaScript 구문 오류: 0
- `pageerror`: 0
- 미정의 클릭 핸들러: 0
- 무반응 핵심 버튼: 0
- 검색·필터·Finder·비교·지도/목록·후기·FAQ·등록 동작 확인
- 로컬 캡처 환경은 외부 DNS가 차단되어 원격 Pretendard 스타일시트 요청이 네트워크 오류로 기록된다. 이는 애플리케이션 JavaScript 오류가 아니다.
- 캡처·동작 검증에서는 외부 스타일 요청을 차단하고 로컬 한국어 폰트 폴백으로 실행해 애플리케이션 콘솔 오류 0을 확인했다.
- 최종 HTML은 연결된 환경에서 Pretendard Variable을 불러오며, 실패 시 시스템 한국어 산세리프로 폴백한다.
