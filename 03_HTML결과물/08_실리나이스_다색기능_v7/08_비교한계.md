# 원본–결과 비교자료의 범위

`comparison/sillynice-method-vs-danjion-v7.mp4`의 왼쪽은 Silly Nice 원본 사이트의 생 브라우저 녹화가 아니라, 공개 라우트·공식 시각 자산·색상·기능 흐름을 정리한 **reference-method audit board**다.

현재 실행 환경의 웹 수집기는 Silly Nice의 일부 클라이언트 렌더링 화면을 일반 페이지 인덱스로 반환했고, 로컬 Chromium은 외부 사이트 접속이 차단돼 실제 사이트 화면 녹화를 만들 수 없었다. 따라서 원본 녹화를 지어내거나 다른 사이트 화면을 대체하지 않았다.

확인 가능한 범위에서 다음을 근거로 사용했다.

- 공개 페이지 인덱스의 Home, Menu, Product Finder, Effects, Product Comparison, Store Locator, Testimonials, Learn, FAQ, Mission, Why, Sustainability, Partnerships, Wholesale 및 지역·계절 랜딩 유형
- 공식 `locations` 페이지의 메뉴·위치목록·연락 연결·하단 CTA 구조
- 공식 블로그·제품 공개 화면과 공식 제품 시각 자산의 색상·오브젝트 처리

추후 실제 브라우저 원본 녹화가 제공되면 같은 비교 규격으로 좌측을 교체할 수 있다. 현재 비교자료는 ‘어떤 원본 영상을 직접 녹화했다’고 주장하지 않는다.
