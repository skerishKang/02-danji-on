# M1 패키지 경로 안내

이 폴더는 **Living Neighbor Shop · Motion Gate M1의 한글 재패키징 보존본**입니다.

## 현재 실행 파일

- `01_단지온_M1_살아있는이웃가게_모션검증.html`
- 실행 이미지: `05_실행자산/scene-*.webp`

HTML은 현재 폴더 구조에서 직접 열었을 때 위 `05_실행자산` 파일을 사용하도록 맞춰져 있습니다.

## `90_SHA256.txt`의 지위

`90_SHA256.txt`는 **원본 영문 패키지 레이아웃에서 생성된 historical source manifest**를 보존한 파일입니다.
그 안의 `assets/`, `captures/`, `reference-frames/`, 영문 문서명·영상명 경로는 현재 이 한글 재패키징 폴더에 대한 상대경로가 아닙니다.

따라서:

- `90_SHA256.txt`의 기존 해시 값을 현재 폴더 파일의 해시라고 재해석하지 않습니다.
- 경로명이 바뀌었다는 이유만으로 기존 SHA-256 값을 임의 재작성하지 않습니다.
- 현재 폴더의 실행 가능 여부는 HTML이 실제 `05_실행자산/scene-*.webp`를 참조하는지로 확인합니다.
- 원본 패키지 전체 무결성 검증이 필요하면 원본 레이아웃 또는 provenance가 유지된 별도 bundle을 기준으로 수행합니다.
