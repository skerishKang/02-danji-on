# 단지온 v7 · Silly Color Interaction Contract

## 핵심 원칙

- 색면 전환은 스크롤 리듬을 만들지만 스크롤을 가로채지 않는다.
- 기능은 모션 종료를 기다리지 않는다.
- 호버·저장·비교·완료 상태는 색뿐 아니라 위치·텍스트·`aria-pressed`로 표시한다.
- `prefers-reduced-motion: reduce`에서는 모든 애니메이션과 부드러운 스크롤을 제거한다.

## 동작 규격

| 항목 | 트리거 | 지속시간 | 상태 변화 | 키보드 |
|---|---|---:|---|---|
| 전체 메뉴 | 메뉴 버튼 | 0~180ms | 라임 전체 화면, 굵은 번호 링크 | Escape 닫기, 첫 닫기버튼 포커스 |
| 히어로 제목 | 첫 로드 | 720ms, 줄 지연 90ms | 줄 아래→제자리 | 모션 제거 가능 |
| 히어로 사진 | 첫 로드 | 800ms | 마스크 아래→전체 | 모션 제거 가능 |
| 사진 느린 확대 | 상시 | 10초 왕복 | 최대 1.04 | reduced-motion에서 정지 |
| 서비스 가로 탐색 | 버튼·좌우키 | 280ms | 한 카드 단위 이동, 위치 표시 | ArrowLeft/Right |
| 분야 필터 | 클릭 | 160ms | 선택 배경+그림자+결과 재렌더 | Tab/Enter/Space |
| 저장 | 클릭 | 120ms | 하트 채움+`aria-pressed`+토스트 | Enter/Space |
| Finder | 버튼·상황 선택 | 180ms | 4단계, 진행바, 이전/다음, 결과 | 모달 포커스 순환 |
| 비교 추가 | 클릭 | 160ms | 버튼 문구·하단 도크·개수 변경 | Enter/Space |
| 비교 보기 | 클릭 | 180ms | 표와 차이 요약 모달 | Escape·Tab trap |
| 지도/목록 | 토글 | 160ms | `aria-pressed`, 동일 위치에서 패널 교체 | Tab/Enter |
| 대표 이웃 | 번호 탭 | 320ms | 사진 페이드, 제목·설명 교체 | Tab/Enter |
| 후기 | 이전/다음 | 160ms | 한 문장 교체 | 버튼 키보드 |
| FAQ | 질문 행 | 250ms | 높이 전환+플러스 회전+aria-expanded | Enter/Space |
| 등록 | CTA | 180ms | 3단계 모달, 검토 요청 완료 토스트 | Escape·Tab trap |
| 브라우저 뒤로가기 | 열린 모달 | 즉시 | 최상위 모달 닫기 | 브라우저 기본 |

## 금지

자동 소리, 스크롤 가로채기, 3D 회전, 모바일 자동 슬라이드, 무한 로딩, 기능을 가리는 인트로, 색만으로 상태 표시.
