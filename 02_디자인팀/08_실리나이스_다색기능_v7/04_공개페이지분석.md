# 단지온 v7 · Silly Nice 공개 화면 감사

검토일: 2026-08-05  
범위: 공개 사용자 화면만. 관리자·SEO 운영 화면은 제외.

## 조사 근거와 제한

- 현재 공개 도메인의 페이지 인덱스에서 Home, Menu, Effects, Product Finder, Product Comparison, Store Locator, Dispensaries Index, Learn, FAQ, Testimonials, Mission, Why, Sustainability, Partnerships, Wholesale와 지역·계절 랜딩 유형을 확인했다.
- 공식 `locations` 공개 화면에서 전체 메뉴, 모바일 메뉴의 열림·닫힘 문구, 위치 목록, 연락·웹사이트 연결, 제품 탐색 CTA와 하단 FAQ·Contact 연결을 확인했다.
- 공식 블로그·제품 공개 화면에서 대형 제목, 긴 편집 콘텐츠, 반복되는 이미지–제목–설명 흐름, 제품 라인업과 상세 진입, Menu 연결을 확인했다.
- 현재 사이트는 클라이언트 렌더링 비중이 높아 이 실행 환경의 웹 수집기에서 일부 라우트의 실제 DOM과 CSS가 일반 페이지 인덱스로 대체되었다. 따라서 **공개 라우트·정보구조·공식 시각 자산은 확인했으나, 모든 화면의 원본 CSS HEX와 프레임 단위 애니메이션 시간을 직접 추출했다고 주장하지 않는다.** 색상 문서에는 공식 시각 자산에서 샘플링한 값과 접근성 조정값을 분리해 기록했다.

## 시각 문법

1. 강한 단색 면과 흰색·검정·크림이 교대한다.
2. 한 섹션의 주색은 하나로 제한해 다색 페이지가 난잡해지지 않게 한다.
3. 제품 패키지처럼 사진을 ‘오브젝트’로 취급한다. 단지온에서는 손·도구·작업공간을 큰 크롭과 비정형 마스크로 사용한다.
4. 굵고 큰 제목, 짧은 본문, 분명한 CTA로 위계를 만든다.
5. 메뉴·Finder·비교·위치·후기·FAQ가 장식이 아니라 발견 흐름을 구성한다.
6. 모바일에서는 같은 색 리듬을 세로로 재배치하고 검색과 주요 행동을 첫 화면에 남긴다.
