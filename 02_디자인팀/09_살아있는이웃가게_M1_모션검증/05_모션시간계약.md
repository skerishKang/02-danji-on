# 03 Motion Timing Contract — M1

## Global principles

- The initial usable interface is present immediately; animation does not disable inputs.
- All first-view entrances complete within 1.4s.
- Shop changes complete within 1.1s.
- No autoplay scene cycling.
- No scroll hijacking.
- Search fields and primary buttons do not translate during use.
- All transitions preserve function under reduced motion.

## Scene 02 scroll mapping — desktop only

- The sticky stage occupies normal document flow.
- Progress 0.00–0.32: food scene.
- Progress 0.33–0.66: learning scene.
- Progress 0.67–1.00: home-care scene.
- Scene thresholds use hysteresis to avoid rapid toggling near boundaries.
- Manual selector click scrolls the normal document to the corresponding threshold.
- The browser remains free to scroll normally.

## Detail layer

- Open: background dim 240ms; panel opacity and y-position 320ms.
- Close: panel 180ms; background restore 220ms.
- Focus moves into the dialog and returns to the triggering control.
- Escape closes the dialog.

## Persistent motion

- Slow selected-photo zoom: 1.00→1.035 over 8s, alternate direction.
- Disabled on mobile data-saving mode and reduced motion.
- No other infinite animation except a low-frequency resident status pulse; pulse is disabled under reduced motion.

## Reduced-motion contract

When `prefers-reduced-motion: reduce` or the user activates the page control:

- sticky scroll scene remains structurally present but no scrub transform is applied,
- selected photos switch with a crossfade no longer than 80ms,
- all reveal elements are immediately visible,
- progress rail updates without animation,
- controls, selection, save and dialog functions remain identical.
