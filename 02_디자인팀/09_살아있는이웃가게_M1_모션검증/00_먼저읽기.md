# 단지온 Motion Gate M1 — READ FIRST

- 작업명: `Living Neighbor Shop`
- 상태: `HOLD_FOR_EXECUTION`
- 목적: 전체 제품 통합 전에 단지온의 모션 정체성 한 가지를 승인한다.

## 이번 Gate의 질문

> 같은 단지 이웃이 실제로 일하는 장면과 검색·선택 기능을 결합해, 기존 아파트 앱과 다른 살아 있는 이웃가게 경험을 만들 수 있는가?

## 입력 기준

- 기능·정보구조: `danjion-neighbor-life-v5-responsive.html`
- 사진·콘텐츠: `danjion-neighbor-life-v5-photos.html`
- 모션 기술 참고: v6와 파디엠 시네마틱 스크롤
- 기능형 상호작용 참고: v7 Finder·비교·지도·대표 이웃
- 참고영상: 제품 오너가 지정한 영상 파일

## 출력

단일 후보 HTML 한 개만 제작한다.

`danjion-living-neighbor-shop-motion-gate-m1.html`

M1 승인 전에는 전체 목록·상세·등록·관리 기능을 새 시각체계에 통합하지 않는다.
