# 단지온 Living Neighbor Shop · Motion Gate M1 실행계약

## 0. 작업 지위

이번 작업은 전체 단지온 재제작이 아니다.

단일 승인 목표:

> 이웃이 실제로 일하는 장면과 단지온의 검색·선택 기능을 결합해 단지온만의 살아 있는 이웃가게 경험을 만든다.

새 파일:

`danjion-living-neighbor-shop-motion-gate-m1.html`

기존 파일 수정·덮어쓰기 금지.

## 1. 제품 의미

첫 화면에서 5초 안에 다음을 이해해야 한다.

- 방림명지로드힐 주민을 위한 서비스
- 같은 단지 주민이 하는 가게와 서비스
- 입주민 전용 혜택
- 바로 검색 가능
- 자신의 일도 등록 가능

## 2. 구성

### Scene 01 — 오늘 일하는 이웃

- 실제 작업사진 또는 짧은 무음 영상
- 손·도구·작업공간 중심
- 제목: `필요한 일, 우리 단지에서 먼저 찾아보세요`
- 검색, `가게와 서비스 찾기`, `내 일 알리기`, 입주민 확인을 즉시 사용 가능하게 표시

### Scene 02 — 일이 바뀌면 장면도 바뀜

최소 세 장면:

1. 반찬을 만드는 이웃
2. 수학을 가르치는 이웃
3. 집과 생활을 고치는 이웃

선택에 따라 사진·영상, 색면, 서비스명, 주민관계, 혜택, 상세 행동이 함께 바뀐다.

### Scene 03 — 살아 있는 가게 선택

가게 목록과 선택된 작업 장면을 같은 화면에 배치한다.

선택 시 갱신:

- 작업 장면
- 설명
- 가격 또는 이용방법
- 혜택
- 위치 또는 방문 방식
- 저장
- 상세보기

### Product Landing

세 장면 이후에는 v5 기준의 명확한 제품 UI로 착지한다.

- 카테고리
- 서비스 목록
- 주민혜택
- 단지소식
- 내 일 알리기

전체 페이지를 영화처럼 만들지 않는다.

## 3. 시각 원칙

- 따뜻한 생활사진
- 짙은 잉크색 본문
- 장면별 의미 있는 강조색
- 한 장면의 강한 색은 하나
- 전체를 파랑 하나 또는 형광 다색으로 통일하지 않음
- 입주민 확인은 별도 상태색

## 4. 모션 계약

최초 진입:

- 사진 마스크: 650~850ms
- 제목 줄 등장: 80~120ms 시차
- 검색·CTA: 전체 1.4초 이내에 안정

장면 전환:

- 선택 피드백: 120~180ms
- 기존 장면 초점 변화: 300~450ms
- 새 장면 공개: 650~950ms
- 정보 패널 갱신: 180~260ms
- 전체 입력 차단: 금지

허용:

- 마스크
- 1.00→1.035 느린 확대
- 제한된 깊이
- 짧은 텍스트 슬라이드
- 정보 패널 전환

금지:

- 스크롤 가로채기
- 자동 소리
- 모바일 자동 장면전환
- 무한 회전
- 검색창·버튼 이동
- 무거운 전체 WebGL
- 의미 없는 AI 오브젝트

## 5. 모바일

390×844 별도 구조.

순서:

`워드마크·검색·내정보 → 입주민 확인 → 작업 장면 → 핵심문구 → 검색 → CTA → 이웃 선택`

- 탭으로 장면 전환
- 포스터 이미지 대체 허용
- 하단 메뉴 5개 유지
- 본문 최소 16px
- 터치영역 최소 48px

## 6. 접근성·성능

- `prefers-reduced-motion` 지원
- 영상 실패 시 정적 이미지와 기능 유지
- 키보드 장면 선택
- `aria-selected`·텍스트 상태
- 가로 overflow 0
- 콘솔 오류 0
- 자동재생 소리 금지
- 데스크톱 모션 자산 권장 8MB 이하
- 모바일 모션 자산 권장 3MB 이하

## 10. 승인 기준

다음을 모두 만족하면 `MOTION_IDENTITY_APPROVED`다.

1. 5초 안에 서비스 목적을 이해함
2. 첫 화면에서 검색 가능
3. 움직임이 이웃의 실제 일과 연결됨
4. 최소 세 장면이 의미 있게 전환됨
5. 장면 선택에 따라 정보와 행동이 실제 변경됨
6. v5의 제품 명확성을 잃지 않음
7. v7보다 차분하고 기존 아파트 앱보다 새로움
8. 모바일이 데스크톱 축소본이 아님
9. reduced-motion에서도 기능 동일
10. 영상과 장식이 검색·선택보다 강하지 않음
