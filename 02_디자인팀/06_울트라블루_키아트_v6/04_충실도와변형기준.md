# 단지온 v6 키아트 — 재현한 부분과 의도적으로 바꾼 부분

## 높은 충실도로 재현한 부분

1. **페이지의 장면 순서**  
   분할 히어로 → 가로 핵심 콘텐츠 → 세 개의 시각적 근거 → 분야 목록 → 숫자 띠 → 대형 교차 밴드 → 고정 위치 선택 패널 → 세로 서사 → 인용 → 시네마틱 사진 → 저널 → 짧은 가입/안내 → 어두운 푸터의 순서를 유지했습니다.

2. **큰 것과 작은 것의 크기 차이**  
   모든 콘텐츠를 같은 카드로 만들지 않고, 57:43 히어로와 대형 사진 밴드, 중형 가로 카드, 작은 텍스트 목록을 교차시켰습니다.

3. **스크롤 리듬과 배경 전환**  
   아이보리·백색·연청색·짙은 남색을 장면 단위로 전환하고, 밀도 높은 구간 뒤에 넓은 여백을 배치했습니다.

4. **이미지 크롭과 텍스트 긴장감**  
   손·도구·작업공간을 과감하게 자르고, 사진 옆 또는 위에 짧고 큰 문장을 배치했습니다.

5. **고정 위치 콘텐츠 교체**  
   분야와 대표 이웃 선택 시 페이지를 이동하거나 레이아웃을 다시 만들지 않고 같은 프레임에서 사진과 설명만 교체합니다.

6. **카메라와 등장 리듬**  
   히어로 마스크 공개, 줄 단위 제목 등장, 8초의 느린 확대, 620ms 섹션 진입을 사용했습니다.

## 단지온 사용성을 위해 의도적으로 바꾼 부분

1. 구매 버튼은 `가게와 서비스 찾기`, `내 일 알리기`, 검색과 문의 행동으로 바꿨습니다.
2. 제품 효능은 주민이 실제로 하는 일과 입주민 혜택으로 바꿨습니다.
3. 영어 장식문구와 브랜드 제품명은 한글 생활언어와 짧은 보조 라벨로 대체했습니다.
4. 원본보다 헤더와 검색을 더 명시적으로 유지했습니다.
5. 모바일에서는 자동 장면 전환, 강한 패럴랙스, 가로 드래그 전용 조작을 제거했습니다.
6. 60~70대 주민을 위해 CTA 52px, 본문 16px, 아이콘·글자 병기를 유지했습니다.
7. 원본의 상품 반복은 주민 관계와 사람의 일 중심 콘텐츠로 변환했습니다.
8. 실제 주민 동의 전에는 시안용 사진만 사용하고 하단에서 한 번 안내합니다.

## 사용하지 않은 원본 요소

- 원본 브랜드명, 상품명, 제품 사진과 카피
- 건강 효능 주장과 구매 가격 구조
- 자동재생 상품 장면
- 작은 영문 장식과 프로모션 배지
- 원본 색상표의 직접 복제
- 사용자가 읽기 전에 넘어가는 전환

## 승인 후 다음 단계

키아트 승인 후 이 장면 문법을 기존 v5의 목록·상세·혜택·소식·내정보·등록 기능에 통합합니다. 승인 전에는 전체 제품 HTML을 수정하지 않습니다.
