# 러브트리 채택본 제작방식 검토

## 확인한 대표 폴더

- `0.첫여정통합-3개html합본`
- `23.메모리그래프관측소`
- `25.메모리필름스튜디오`
- `39.팝업시즌기억책`
- `42.메모리아틀라스`

## 공통적으로 확인된 제작 구조

1. 원본 영상과 최종 HTML을 같은 폴더에 둔다.
2. 원본을 일정 간격 이미지가 아니라 의미 있는 장면 단위 키프레임으로 분해한다.
3. `execution-contract`에서 화면 역할, 상태, 금지사항, 제출물을 구현 전에 잠근다.
4. `reference-analysis`와 별도의 렌더링/구조 보고서로 원본의 공간, 장면, 카메라 문법을 설명한다.
5. 데스크톱·모바일 실행 영상과 정적 캡처를 모두 만든다.
6. 원본과 결과를 나란히 둔 비교 산출물을 만든다.
7. validation 폴더 안에서 상태별 캡처와 비교 이미지를 분리한다.
8. SHA 또는 manifest로 제출물 누락과 버전 혼선을 방지한다.
9. 첫 버전에서 끝내지 않고 V1–V4처럼 시각 잠금과 수정 결과를 남긴다.

## 단지온에 적용한 방식

- 주 벤치마크에서 19개 키프레임을 추출했다.
- 장면 순서를 유지한 채 상품/효능/구매를 주민의 일/생활 도움/검색·문의로 변환했다.
- 화면 문법을 확인하기 위한 키아트만 만들고 전체 기능은 결합하지 않았다.
- 데스크톱과 모바일 실행 영상을 따로 만들고 원본과 결과를 나란히 비교한다.
- 검증 결과와 의도적 차이를 문서로 고정한다.

## 핵심 판단

러브트리 채택본의 품질은 장식의 수가 아니라, 원본의 장면 구성과 동작을 먼저 계약으로 고정하고 결과와 나란히 검증한 데서 나온다. 단지온도 같은 절차를 적용하되 고령 사용자 접근성과 즉시 검색이라는 제품 제약을 우선한다.
