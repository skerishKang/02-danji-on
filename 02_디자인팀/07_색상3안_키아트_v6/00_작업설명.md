# 단지온 v6 키아트 색상 재검증

이 패키지는 전체 기능 통합 전 키아트 색상 선택용입니다.

## 독립 마스터 HTML
- danjion-keyart-color-a-ultrablue.html
- danjion-keyart-color-b-copper-editorial.html
- danjion-keyart-color-c-aubergine-apricot.html

세 파일은 iframe 진입점이 아니며, 각각 전체 HTML·CSS·JavaScript를 포함합니다.

## 공통 교정
- 768px 태블릿 제목 크기와 제목 영역 비율 조정
- `word-break: keep-all`
- `overflow-wrap: normal`
- 제목 각 줄 `white-space: nowrap`
- 1024, 768, 430, 390, 360, 320px 검증 대상으로 지정

전체 서비스 기능 통합은 보류합니다.
