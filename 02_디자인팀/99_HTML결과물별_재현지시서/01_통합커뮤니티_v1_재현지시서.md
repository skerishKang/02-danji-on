# 단지온 01_통합커뮤니티_v1 재현지시서

## 0. 지위

이 문서는 단지온 초기 **통합 아파트 커뮤니티 기능검증본**을 다시 만드는 독립형 프롬프트다. 현재 단지온의 생활경제 중심 제품방향과는 다르며, 역사적 기능범위 검증본을 재현하는 것이 목적이다.

대표 결과 파일명:
`01_단지온_v1_통합커뮤니티.html`

## 1. 목표

방림명지로드힐 주민용 통합 커뮤니티 프로토타입을 단일 HTML/CSS/JavaScript 파일로 구현한다. 공지·현안·주민참여·커뮤니티·주민가게를 한 화면체계 안에서 검증한다.

## 2. 시각체계

- Pretendard/Noto Sans KR 계열 산세리프.
- 밝은 회백색 배경, 흰색 패널.
- 대표색은 짙은 청록 `#0c655b` 계열.
- 보조색: 남색, 코랄, 노랑, 빨강, 녹색 상태색.
- 카드 모서리 약 8~16px, 얕은 그림자.
- 공공·관리 서비스처럼 정돈되고 신뢰 중심.
- 당시 결과의 성격을 재현하기 위해 녹색/청록 중심 UI를 유지한다.

## 3. 데스크톱 구조

상단 고정 헤더:
- `단지온` 브랜드 마크
- 단지명
- 공지/현안/주민참여/커뮤니티/우리동네 성격의 메뉴
- 검색 또는 사용자 도구

홈 주요 영역:
1. 단지 상황과 주요 행동을 보여주는 히어로/컨텍스트 영역
2. 긴급 공지 스트립
3. 공식 공지 목록: 발신주체, 제목, 날짜, 중요도
4. 단지 현안 카드
5. 입대의/관리사무소 활동 또는 일정
6. 주민참여 현황/설문·제안 등의 타일
7. 주민 커뮤니티·장터·이벤트
8. 주민가게/서비스 소개

내부 화면도 같은 HTML에서 라우트 전환 방식으로 구현한다.

## 4. 핵심 기능

실제로 작동하게 구현:
- 메뉴 이동
- 공지 목록→상세
- 현안 상세와 진행상태
- 주민참여/설문/제안형 상태 전환
- 검색
- 필터/탭
- 주민가게 간단 탐색
- 모달·토스트
- 모바일 하단 내비게이션

백엔드 없이 브라우저 메모리/정적 데이터로 동작한다.

## 5. 모바일

390×844 기준:
- 데스크톱 헤더를 모바일 상단바로 재구성
- 하단 고정 내비게이션
- 표형 정보는 세로 카드/행으로 재배치
- 본문 15~17px 이상
- 터치대상 44~48px 이상
- 가로 스크롤 금지

## 6. 콘텐츠 예시

- 단지명: 방림명지로드힐
- 공식 공지: 입주자대표회의, 관리사무소, 선거관리위원회 등
- 현안: 시설보수, 일정, 검토/완료 상태
- 주민참여: 설문/제안/참여수 등 예시
- 주민가게: 같은 단지 주민이 하는 소규모 가게/서비스

실제 개인정보나 실제 동·호수는 넣지 않는다.

## 7. 기술조건

- 단일 HTML 파일
- 별도 빌드도구 금지
- 반응형 CSS
- JavaScript로 화면상태 관리
- 키보드 포커스 표시
- 콘솔 오류 0
- 모든 버튼은 작동하거나 명시적으로 비활성 상태를 보인다.
