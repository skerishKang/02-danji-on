# 단지온 06_울트라블루_키아트_v6 재현지시서

## 0. 지위

v5의 제품성을 유지하면서 벤치마크 영상의 장면문법을 강하게 적용한 **울트라블루 키아트/모션 실험**을 재현한다. 이 결과는 역사적으로 미채택 실험이므로 현재 공식 브랜드로 승격하지 않는다.

## 1. 핵심 레퍼런스 문법

반드시 다음 흐름을 만든다.
1. 평평하고 절제된 헤더 + 전폭 키비주얼
2. 히어로를 두 개의 강한 사진/색면으로 분할하고 제목이 시각적 긴장을 가로지름
3. 바로 이어지는 가로 탐색 레일
4. 중앙 편집형 3개 이미지 스토리
5. 6개 필요 분야 + 숫자 증거 밴드
6. 동일 카드 반복 대신 대형 사진 피처 밴드 교차
7. 어두운 고대비 필요선택 장면에서 콘텐츠가 같은 자리에서 교체
8. 주민 이야기 세로 패널 3개 + 인용 장면 + 느린 시네마틱 사진 장면
9. 저널 카드 3개 + 파일럿/구독 밴드 + 이미지 스트립 푸터
10. 큰→작은→큰 스크롤 리듬

## 2. 단지온 의미변환

- 제품 → 주민 운영 가게/서비스
- 제품사진 → 손/도구/작업공간/작업결과
- 효능 → 무엇을 하고 어떤 문제를 해결하는지
- 구매 → 검색/문의방법/주민혜택/저장
- 브랜드스토리 → 같은 단지 이웃의 일
- 회원혜택 → 입주민 확인 전용 혜택

## 3. 필수 첫 화면

- `방림명지로드힐`
- 입주민 확인
- 검색
- `가게와 서비스 찾기`
- `내 일 알리기`

애니메이션이 끝나기 전에도 모두 사용할 수 있어야 한다.

## 4. 시각

- 크림/본색 바탕
- 울트라블루가 매우 강한 핵심 색면을 형성
- 큰 실사사진과 강한 블루색 면을 대칭/비대칭으로 병치
- Pretendard 중심
- 직선적 편집 레이아웃
- 어두운 선택 섹션 포함

## 5. 모션 고정

- 히어로 마스크 공개 680ms
- 제목 550ms, 줄간 100ms 시차
- 히어로 사진 8초 동안 최대 5% 확대
- 패널 교체 fade-out 170~190ms, 전체 340ms 이내
- 가로 레일 부드러운 이동 약 320ms 체감
- 저장/완료 피드백 150~220ms
- 섹션 공개 620ms
- reduced-motion에서 장식모션 제거

## 6. 모바일

- 390×844 첫 화면에 검색 표시
- 5개 라벨형 하단 메뉴
- 본문 16px 이상
- 주요 버튼 52px 이상
- 터치 48px 이상
- 데스크톱을 단순 축소하지 말고 재배치

## 7. 금지

- 스크롤 가로채기
- 자동 오디오
- 자동 캐러셀
- 3D 회전
- 필수기능 숨김
- iframe으로 데스크톱/모바일 별도 후보인 척하는 방식

## 8. 출력

대표 HTML:
- `01_단지온_v6_울트라블루_키아트.html`

통합/편집모션 HTML:
- `02_단지온_v6_울트라블루_편집모션.html`

필요하면 데스크톱/모바일 실행 진입 HTML을 만들되 같은 마스터를 iframe으로 감싼 것이라면 별도 디자인안으로 계산하지 않는다.

제출:
- 1440×1100, 768×1024, 390×844, 320×720 캡처
- 전체페이지 캡처
- 키프레임 비교
- 검증 문서
- SHA256

결과상태는 `미채택 실험`으로 표시한다.
