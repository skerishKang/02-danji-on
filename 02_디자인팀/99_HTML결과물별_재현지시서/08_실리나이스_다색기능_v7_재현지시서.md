# 단지온 08_실리나이스_다색기능_v7 재현지시서

## 0. 지위

Silly Nice의 공개 웹 경험에서 **강한 다색 구역, 메뉴, Finder, 비교, 위치탐색, 후기/FAQ 등의 상호작용 문법**을 단지온 기능으로 번역한 v7 실험을 재현한다. 로고·카피·사진·소스코드를 복제하지 않는다. 결과는 현재 미채택 실험이다.

## 1. 제품 변환

원본 상업 UX → 단지온:
- Menu → 이웃가게 전체 목록
- Product Finder → `필요한 일 찾기` 4단계 안내
- Effects → 상황으로 찾기
- Product Comparison → 서비스 비교
- Store Locator → 우리 단지 주변 지도/목록
- Product Detail → 가게·서비스 상세
- Testimonials → 주민 이용 이야기
- FAQ → 도움말
- Partnerships/Wholesale → 내 일 알리기/제휴 신청

쇼핑카트·결제·대마 관련 규제콘텐츠·관리자/SEO 페이지는 만들지 않는다.

## 2. 시각문법

- 화면 구역마다 매우 다른 강한 색면
- 검정/흰색/크림을 구조색으로 사용
- 한 구역의 주강조색은 하나
- 대담한 Pretendard 타이포
- 큰 번호와 직관적 상태변화
- 두꺼운 검정선과 박스 그림자를 일부 적극 사용
- 밝은 라임/핑크/오렌지/보라/블루 계열의 강한 대비

이 버전은 의도적으로 캠페인성/실험성이 강하다.

## 3. 필수 기능

실제 작동:
- 전체 화면 메뉴
- 홈 검색
- 가로 서비스 탐색
- 분야 필터
- 저장
- `필요한 일 찾기` Finder 4단계 + 결과
- 비교 추가/하단 도크/비교표 모달
- 지도/목록 토글
- 대표 이웃 번호탭
- 주민 이야기 이전/다음
- FAQ 아코디언
- 내 일 등록 3단계 모달
- 토스트
- 브라우저 뒤로가기 시 열린 모달 닫기

## 4. 상호작용 시간

- 메뉴 0~180ms
- 히어로 제목 720ms, 90ms 시차
- 사진 마스크 800ms
- 사진 최대 1.04 느린 확대, 10초 왕복
- 레일 280ms
- 필터 160ms
- 저장 120ms
- Finder 180ms
- 비교 160~180ms
- 지도/목록 160ms
- 대표 이웃 320ms
- FAQ 250ms
- 등록 모달 180ms

## 5. 접근성

- 상태를 색만으로 표시하지 않음
- `aria-pressed`, `aria-expanded`, `aria-selected`
- 모달 Tab trap/Escape
- ArrowLeft/Right 레일 지원
- reduced-motion에서 애니메이션과 smooth scroll 제거
- 모바일 자동 슬라이드 금지
- 자동 소리 금지

## 6. 출력

두 파일을 만들되 내용이 동일한 경우 결과안내에 동일 SHA임을 명시한다.
