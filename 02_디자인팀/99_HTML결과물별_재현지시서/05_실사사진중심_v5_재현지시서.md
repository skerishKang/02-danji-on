# 단지온 05_실사사진중심_v5 재현지시서

## 0. 지위

단지온의 현재까지 발전과정에서 **기능·정보구조 기준선으로 가장 중요한 v5 반응형 결과**와, 같은 시기의 **실사사진 중심 디자인 참고본**을 함께 재현한다.

반드시 두 HTML을 만든다.

1. `01_단지온_v5_반응형기능기준.html`
2. `02_단지온_v5_실사사진중심_참고.html`

## 1. 공통 제품목표

- 같은 단지 주민이 하는 가게와 서비스를 찾는다.
- 검색이 첫 화면에서 보인다.
- 주민전용 혜택을 확인한다.
- 내 일을 등록한다.
- 단지소식은 하단 보조기능이다.
- 모바일 하단 메뉴는 홈/이웃가게/주민혜택/단지소식/내정보 5개.

## 2. 시각체계

- Pretendard Variable
- canvas `#F7F7F4`
- paper `#FFFFFF`
- ink `#171717`
- muted `#66635E`
- accent 코랄 `#D84F32`
- verified `#277A53`
- 선 `#D8D5CE`
- 라운드는 6~8px 중심으로 절제
- 그림자 최소
- 실제 사진이 화면의 중심

사진 톤:
- 사람의 얼굴보다 손, 도구, 작업공간, 실제 결과물
- 채도 약간 낮추고 현실적인 생활사진
- 동일한 스톡 느낌을 피함

## 3. `01_반응형기능기준` 홈

데스크톱 12열:
- 왼쪽 7열 큰 실사사진
- 오른쪽 5열 제목/설명/CTA/검색
- 제목: 필요한 일, 우리 단지에서 먼저 찾는다는 의미
- `가게와 서비스 찾기`, `내 일 알리기`
- 검색창과 검색 예시
- 현재 소개 서비스 수

다음 영역:
- 대표 이웃 2개 미리보기
- 번호형 카테고리 목록
- 대표 이웃 1 + 중간 이웃 2 + 텍스트 목록
- 주민혜택 밴드
- 단지소식 얇은 목록

## 4. `01_반응형기능기준` 실제 기능

반드시 작동:
- 홈
- 이웃가게 목록
- 검색
- 카테고리/관계 필터
- 가게 상세
- 사진 갤러리
- 찜
- 문의안내
- 주민혜택
- 단지소식
- 내정보
- 입주민 확인
- 내 일 등록
- 등록/모달/토스트
- 글자크기 또는 접근성 보조
- 모바일 하단 내비게이션

정적 데이터 기반 SPA로 구현.

## 5. `02_실사사진중심_참고`

같은 제품이지만 기능보다 **브랜드·사진 편집감**을 강화한다.
- 사진 비중 확대
- 대표 이웃을 더 크게
- 편집형 불균형 그리드
- 목록/CTA는 단순하게
- v3/v4의 인공 그래픽보다 실제 작업사진을 우선
- 기능 일부는 참고본 수준이어도 되지만 검색·대표 서비스 선택은 반응해야 한다.

## 6. 모바일

390×844:
- 검색이 초기 뷰포트 안에 들어옴
- 사진→제목→검색→CTA 순서가 명확
- 5개 하단 메뉴
- 본문 16px 이상
- 핵심 버튼 52px 권장
- 모든 터치대상 48px 이상
- 가로 overflow 0

추가 검증: 320×720, 360×800, 430×932, 768×1024, 1024×768.

## 7. 접근성

- 키보드 포커스
- 색상만으로 상태표시 금지
- `aria-*` 사용
- 모달 포커스 관리
- `prefers-reduced-motion`
- 버튼 무반응 금지

## 8. 제출

필수 HTML 2개와 다음 캡처:
- 홈 데스크톱
- 홈 모바일
- 목록 데스크톱
- 상세 데스크톱
- 주민혜택 데스크톱
- 내정보/프로필 데스크톱

`01_단지온_v5_반응형기능기준.html`을 향후 제품 기능·정보구조 기준선으로 간주하도록 결과안내에 명시한다.
