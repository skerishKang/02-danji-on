# 단지온 02_이웃생활경제_v2 재현지시서

## 0. 지위

단지온이 종합 아파트 커뮤니티에서 **주민 가게·서비스 중심 생활경제 서비스**로 범위를 좁힌 v2 결과를 재현한다. 이 버전의 녹색·이모지·라운드 카드 스타일은 이후 폐기됐지만 역사적 결과 재현을 위해 그대로 유지한다.

대표 결과 파일명:
`01_단지온_v2_이웃생활경제.html`

## 1. 제품목표

첫 화면에서 주민이 다음을 이해하게 한다.
- 우리 단지 주민이 하는 가게와 서비스를 찾는 곳
- 주민 혜택이 있음
- 나도 내 일을 등록할 수 있음
- 단지소식은 보조 기능

## 2. 시각체계

- Pretendard 중심.
- 대표색 짙은 녹색 `#0d6658`, 보조 코랄/남색.
- 밝은 `#f7f8f6` 배경과 흰 카드.
- 12~24px 라운드, 친근한 생활앱 톤.
- 파스텔 그라데이션과 이모지/큰 아이콘을 서비스 이미지 대용으로 사용.
- 그림자는 얕게.
- 고령 사용자용 큰 글자와 큰 버튼.

## 3. 홈 구조

1. `방림명지로드힐`과 입주민 상태가 보이는 헤더
2. 녹색/파스텔 히어로
3. 단지 중요소식 한 줄
4. 큰 검색영역 `무슨 일이 필요하세요?`
5. 4개 큰 메뉴/행동 카드
6. 주민 가게·서비스 4열 카드
7. 주민혜택 카드
8. 새로 등록된 이웃
9. 단지소식 목록

## 4. 서비스 카드

각 카드:
- 업종을 상징하는 이모지 또는 그래픽
- 주민관계 배지
- 가게/서비스명
- 한 줄 설명
- 가격/이용방법
- 주민혜택
- 찜 버튼

주민 직접 운영 → 주민 가족/이웃 → 일반 동네가게 순으로 표현한다.

## 5. 내부 기능

실제로 동작:
- 홈/이웃가게/주민혜택/단지소식/내정보
- 검색
- 카테고리 필터
- 관계 필터
- 서비스 상세
- 이미지/이모지 갤러리
- 찜
- 문의 안내
- 입주민 인증 모달
- 주민 사업자 등록
- 글자크기 확대
- 토스트

백엔드 없이 정적 데이터와 브라우저 상태로 구현한다.

## 6. 상세 화면

- 대표 이미지/이모지
- 가게·서비스명
- 주민관계
- 설명
- 가격
- 주민혜택
- 이용지역/방법
- 문의 행동
- 저장

## 7. 모바일

- 본문 약 17px, 큰글자모드 19px
- 주요 버튼 48px 이상
- 하단 5개 메뉴
- 검색은 첫 화면에서 쉽게 발견
- 카드 1열 또는 2열
- 가로 스크롤 금지

## 8. 제출

- `01_단지온_v2_이웃생활경제.html`
- 데스크톱 1440×1100
- 태블릿 768×1024
- 모바일 390×844
- 모바일 전체페이지
