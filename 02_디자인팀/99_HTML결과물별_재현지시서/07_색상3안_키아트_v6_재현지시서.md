# 단지온 07_색상3안_키아트_v6 재현지시서

## 0. 지위

v6 울트라블루 키아트의 **구조·사진·카피·모션·JavaScript는 동일하게 유지하고 색상 토큰만 3개 독립안으로 비교**한 실험을 재현한다. 현재는 미채택 실험이다.

## 1. 출력 HTML 3개

1. `01_색상안A_울트라블루.html`
2. `02_색상안B_코퍼에디토리얼.html`
3. `03_색상안C_오베르진애프리콧.html`

세 파일은 iframe이 아니라 각각 전체 HTML/CSS/JavaScript를 가진 독립 마스터여야 한다.

## 2. 공통 구조

06 울트라블루 키아트와 동일:
- 히어로 분할 장면
- 검색/CTA/입주민상태
- 가로 서비스 레일
- 3개 편집 스토리
- 6개 카테고리
- 대형 사진 피처
- 어두운 필요선택 장면
- 주민 이야기
- 저널/파일럿/푸터

카피·사진·컴포넌트 위치·모션을 세 안에서 바꾸지 않는다.

## 4. 반응형 교정

반드시:
- `word-break: keep-all`
- `overflow-wrap: normal`
- 지정된 큰 제목 줄에만 `white-space: nowrap`
- 1024, 768, 430, 390, 360, 320px 검증
- 768px에서 한국어 제목이 한 글자 단위로 찢어지지 않음
- 가로 overflow 0

`white-space: nowrap`을 본문이나 긴 문구 전체에 전역 적용하지 않는다.

## 5. 비교조건

- 세 안의 모든 기능 동일
- 사진 동일
- 문구 동일
- 타이포 동일
- 모션 동일
- 색상만 바뀜

따라서 사용자가 색상 차이를 순수하게 비교할 수 있어야 한다.

## 6. 검증

- 주요 텍스트/배경 조합 WCAG AA 4.5:1 이상
- 태블릿/모바일 제목 줄바꿈 검증
- 콘솔 오류 0
- 모바일 터치 48px 이상
- 본문 16px 이상
