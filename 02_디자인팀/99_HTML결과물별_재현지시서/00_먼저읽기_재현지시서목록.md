# 단지온 HTML 결과물별 재현지시서 목록

## 목적

이 폴더는 `03_HTML결과물`의 01~09 발전과정을 다시 만들어야 할 때 사용하는 **독립형 재현 프롬프트 보관소**다.

각 `01_...md`~`09_...md`는 해당 파일 **하나만 새 디자인팀장/코딩 담당자에게 전달해도** 제품 배경, 화면구조, 시각규칙, 기능, 반응형, 제출파일명을 이해할 수 있도록 작성한다.

다만 생성형 구현은 비결정적이므로, 프롬프트만으로 기존 HTML의 바이트·픽셀 단위 완전 동일성을 보장하지 않는다. 목표는 **동일한 제품범위·정보구조·시각언어·상호작용을 최대한 동일하게 재현**하는 것이다. 완전 동일한 결과가 필요하면 해당 HTML 원본과 캡처도 함께 제공한다.

## 사용 원칙

- 과거 버전의 재현지시서는 **역사적 결과 재현용**이며 현재 승인방향을 자동으로 되살리는 문서가 아니다.
- 기존 HTML 원본은 수정·삭제·덮어쓰지 않는다.
- 새 재현 결과는 원본과 혼동되지 않도록 별도 작업폴더에서 제작한다.
- 개인정보·실제 주민정보를 새로 넣지 않는다.
- 저장장소는 Google Drive, D드라이브, 외장디스크 어느 쪽이든 가능하며 절대경로를 코드에 넣지 않는다.
