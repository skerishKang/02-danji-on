# 단지온 09_살아있는이웃가게_M1 모션검증 재현지시서

## 0. 지위

단지온 전체를 다시 만드는 작업이 아니다. **이웃이 실제로 일하는 장면 + 검색·선택 기능**을 결합한 `살아 있는 이웃가게` 모션 정체성을 검증한다.

대표 결과:
`01_단지온_M1_살아있는이웃가게_모션검증.html`

## 1. 첫 5초에 전달할 것

- 방림명지로드힐 주민을 위한 서비스
- 같은 단지 주민이 하는 가게와 서비스
- 주민 전용 혜택
- 바로 검색 가능
- 나도 내 일을 알릴 수 있음

## 2. 장면구성

### Scene 01 — 오늘 일하는 이웃
- 손·도구·작업공간 중심의 실제 작업사진 또는 짧은 무음 영상
- 제목 `필요한 일, 우리 단지에서 먼저 찾아보세요`
- 검색
- `가게와 서비스 찾기`
- `내 일 알리기`
- 입주민 확인

모션이 끝나기 전부터 검색/버튼 사용 가능.

### Scene 02 — 일이 바뀌면 장면도 바뀜
최소 3개:
1. 반찬을 만드는 이웃
2. 수학을 가르치는 이웃
3. 집과 생활을 고치는 이웃

선택 때 동시에 갱신:
- 사진/영상
- 색면
- 서비스명
- 주민관계
- 주민혜택
- 상세행동

### Scene 03 — 살아 있는 가게 선택
한쪽 가게목록, 다른쪽 선택 작업장면.
선택 시 작업장면/설명/가격 또는 이용방법/혜택/위치 또는 방문방식/저장/상세보기 갱신.

### Product Landing
모션 장면 뒤에는 v5의 명확한 제품 UI로 착지:
- 카테고리
- 서비스 목록
- 주민혜택
- 단지소식
- 내 일 알리기

전체 페이지를 영화처럼 만들지 않는다.

## 3. 시각원칙

- 따뜻한 생활사진
- 짙은 잉크색
- 장면별 의미 있는 강조색
- 한 장면 강한 색 하나
- 전체 파랑 단색 금지
- 형광 다색 과다 금지
- 입주민 확인은 별도 초록 상태색

## 4. 모션

최초:
- 사진 마스크 650~850ms
- 제목 줄 80~120ms 시차
- 검색·CTA 전체 1.4초 이내 안정

장면전환:
- 선택 피드백 120~180ms
- 기존 장면 초점/축소 300~450ms
- 새 장면 공개 650~950ms
- 정보패널 180~260ms
- 입력차단 금지

허용:
- 마스크 공개
- 1.00→1.035 느린 확대
- 제한된 깊이
- 짧은 텍스트 슬라이드
- 정보패널 교체

금지:
- 스크롤 가로채기
- 자동 소리
- 모바일 자동 장면전환
- 무한 회전
- 검색창/버튼 이동
- 무거운 전체 WebGL
- 가게와 관계없는 AI 오브젝트

## 5. 모바일 390×844

순서:
`워드마크·검색·내정보 → 입주민 확인 → 작업장면 → 핵심문구 → 검색 → CTA → 이웃선택`

- 탭으로 장면전환
- 무거운 영상은 포스터 이미지 대체 가능
- 하단 5개 메뉴
- 본문 16px 이상
- 터치 48px 이상

## 6. 접근성/성능

- `prefers-reduced-motion`
- 영상 실패 시 정적 이미지와 모든 기능 유지
- 키보드 장면선택
- `aria-selected`
- 가로 overflow 0
- 콘솔 오류 0
- 자동재생 소리 금지
- 데스크톱 모션자산 권장 8MB 이하
- 모바일 모션자산 권장 3MB 이하
