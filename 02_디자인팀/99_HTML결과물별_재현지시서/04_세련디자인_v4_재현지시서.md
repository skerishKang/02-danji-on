# 단지온 04_세련디자인_v4 재현지시서

## 0. 지위

v3의 편집형 개성을 유지하되 명조 중심의 무거움을 줄이고 **Pretendard 중심의 현대적 제품 UI**로 다듬은 v4를 재현한다.

대표 결과 파일명:
`01_단지온_v4_세련디자인.html`

## 1. 시각목표

- 잡지형 v3보다 더 현대적이고 사용하기 쉬움
- 일반 아파트 앱보다 세련되지만 기능 위치가 즉시 보임
- Pretendard Variable 중심
- 본색/종이색 + 울트라마린 + 제한적 구리색
- 완전 평면이 아니라 얕은 깊이와 적당한 라운드

## 2. 토큰

- canvas `#F1EEE5`
- paper `#FBFAF5`
- ink `#171614`
- muted `#6B675E`
- line `#E4DED1`
- ultramarine `#2C43E8`
- ultramarine deep `#1F32C4`
- ultramarine soft `#E9EBFD`
- copper `#AE6844`
- verified `#2E6B4F`
- radius: 10/16/24px 계층

## 3. 헤더

- 고정형 반투명 헤더
- 텍스트 `단지온` 워드마크
- 입주민 확인된 단지명은 작은 초록 상태칩
- 우측 내비게이션은 라운드 탭 형태
- 활성 메뉴는 울트라마린 소프트 배경

## 4. 홈

히어로:
- 2열, 왼쪽 제목/설명/CTA, 오른쪽 큰 편집 비주얼
- 제목은 44~72px 굵은 Pretendard
- 핵심어만 울트라마린
- CTA는 울트라마린 실버튼 + 흰 보조버튼

검색:
- 큰 흰색 검색 카드
- 밑줄형 입력 + 검정 검색버튼

분야:
- 3열 카테고리 카드
- 번호 + 미니 SVG 아이콘 + 분야명 + 예시
- 울트라마린/구리색 아이콘 배경

이웃:
- 대표 1개 큰 카드 + 우측 작은 카드 2개
- 아래 텍스트형 이웃 목록

혜택:
- 울트라마린→구리색 그라데이션 배너

단지소식:
- 단정한 텍스트 목록

## 5. 목록·상세

- 목록은 검색/필터와 3열 서비스 카드
- 대표 서비스는 더 큰 카드로 강조 가능
- 상세는 큰 이미지, 서비스 설명, 가격, 혜택, 주민관계, 문의
- 관계 확인은 초록색 작은 칩

## 6. 기능

- SPA 방식 화면 전환
- 검색/필터
- 상세
- 찜
- 문의/모달
- 모바일 메뉴
- 토스트
- 포커스 상태

## 7. 반응형

- 1440 데스크톱 / 768 태블릿 / 390 모바일
- 모바일은 한 열 중심
- 본문 16px 이상
- 48px 터치대상
- 가로 overflow 금지

## 8. 제출

- `01_단지온_v4_세련디자인.html`
- 홈 데스크톱
- 홈 모바일
- 목록 데스크톱
- 상세 데스크톱

v3보다 명조·모노 사용을 줄이고 **Pretendard 기반 제품성**이 강해야 한다.
