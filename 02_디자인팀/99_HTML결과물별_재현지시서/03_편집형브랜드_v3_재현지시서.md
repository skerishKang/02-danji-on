# 단지온 03_편집형브랜드_v3 재현지시서

## 0. 지위

v2의 공공·복지앱 인상을 제거하고 단지온을 **편집형 주민 생활경제 브랜드**로 전면 재설계한 v3를 재현한다.

대표 결과 파일명:
`01_단지온_v3_편집형브랜드.html`

## 1. 핵심 문장

`가까이 사는 사람들의 일을 발견합니다.`

단지온은 같은 아파트 주민이 하는 가게와 서비스를 먼저 발견하고 주민혜택을 연결하는 서비스다.

## 2. 색상과 서체

색상 출발점:
- canvas `#F1EEE5`
- paper `#FBFAF5`
- ink `#11110F`
- muted `#625F57`
- line `#C9C3B7`
- ultramarine `#2C43E8`
- copper `#AE6844`
- verified `#315C48`

서체:
- 큰 제목: 한국어 명조/Noto Serif CJK KR/NanumMyeongjo 계열
- UI: Pretendard/SUIT/Noto Sans KR
- 작은 영문·번호: 모노 계열

## 3. 아트디렉션

- 독립 출판물/잡지 같은 12열 편집 그리드
- 넓은 여백
- 거의 사각형에 가까운 모서리(0~4px)
- 카드 그림자 거의 사용하지 않음
- 선과 여백으로 구획
- 동일 카드 4개 반복 금지
- 이모지 금지
- 이미지가 없으면 단색면+타이포그래피/추상 SVG 플레이스홀더

## 4. 홈

헤더:
- 텍스트 워드마크 `단지온`
- 작은 영문 보조표기
- 방림명지로드힐
- 찾기/주민혜택/단지소식/내정보

히어로:
- 왼쪽 7열 대형 명조 제목
- 오른쪽 5열 울트라마린 편집 오브젝트
- `내 일도 알리기`, `이 이웃의 일 보기`
- 주민 확인 상태는 작은 초록 점/캡션

검색:
- 전폭에 가까운 편집형 밴드
- 밑줄형 대형 검색 입력
- `무슨 일이 필요하세요?`

분야:
- 번호 01~06이 있는 전폭 행 목록
- 먹고 마시는 일 / 집을 돌보는 일 / 배우고 가르치는 일 / 몸과 마음 / 사업을 돕는 일 / 만들고 기록하는 일

우리 단지 이웃:
- 대표 1명 큰 비주얼
- 중간 2명
- 나머지 텍스트 목록

주민혜택:
- 구리색 전폭 배너

단지소식:
- 얇은 텍스트 행 목록

## 5. 목록·상세

목록:
- 큰 편집형 페이지 제목
- 관계 탭
- 주민 우선 정렬
- 사진/추상 비주얼 중심의 불균등 그리드

상세:
- 작업사진/비주얼
- 무엇을 하는 이웃인지
- 서비스/가격/혜택/이용방법
- 관계확인 의미
- 문의 행동

## 6. 상호작용

- 메뉴 라우팅
- 검색
- 분야 필터
- 관계 탭
- 상세 진입
- 저장
- 문의 모달
- 짧은 페이드/밑줄 이동/이미지 1~2% 확대
- `prefers-reduced-motion` 지원

## 7. 워드마크 비교 흔적

당시 브랜드명 비교 목적을 반영해 `단지온`, `단지사이`, `이웃일` 워드마크 비교 캡처를 만들 수 있어야 한다. 단, 대표 HTML은 `단지온`을 사용한다.

## 8. 제출

- `01_단지온_v3_편집형브랜드.html`
- 홈 데스크톱/모바일 캡처
- 목록 데스크톱/모바일 캡처
- 상세 데스크톱/모바일 캡처
- 워드마크 비교 캡처

전체는 단일 HTML/CSS/JavaScript로 동작하고, 실제 주민 개인정보는 사용하지 않는다.
