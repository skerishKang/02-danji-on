# 단지온 v3 Editorial — 1차 브랜드 시안 기록

## 제출 범위

- 데스크톱 홈 1440×1100
- 모바일 홈 390×844
- 가게·서비스 목록
- 가게·서비스 상세
- 단지온 / 단지사이 / 이웃일 워드마크 비교

브랜드 승인 전 확장 화면은 구현하지 않았으며, 해당 메뉴는 범위 안내 피드백만 표시한다.

## 색상표

- Canvas `#F1EEE5`
- Paper `#FBFAF5`
- Ink `#11110F`
- Muted `#625F57`
- Line `#C9C3B7`
- Ultramarine `#2C43E8`
- Copper `#AE6844`
- Signal `#D34D2F`
- Verified `#315C48` — 주민 확인 상태에만 제한 사용

## 타이포그래피

- Display: `Noto Serif CJK KR`, `NanumMyeongjo`, Georgia, serif
- Interface: Pretendard, SUIT, `Noto Sans KR`, Apple SD Gothic Neo, `NanumGothic`
- Numeric / editorial label: `NanumGothicCoding`, SFMono-Regular, Consolas

외부 글꼴 파일을 포함하지 않고 운영체제에 설치된 글꼴과 안전한 대체 서체를 사용한다.

## 이미지 자산

- 외부 스톡사진: 사용하지 않음
- 생성형 이미지: 사용하지 않음
- 현재 시각물: HTML 내부의 원본 SVG 편집 그래픽
- 상태: 1차 브랜드 승인용 임시 자산
- 실제 출시 전 교체 대상: 주민의 손, 작업도구, 상품, 작업공간을 동일 촬영 가이드로 제작한 사진

## 레퍼런스 적용 원리

### Stripe Press

- 큰 명조 제목과 넓은 여백
- 편집 지면 같은 비대칭 12열 구조
- 얇은 선으로 정보 계층 구분
- 한 장면에 하나의 중심 콘텐츠

### Complete Shelf

- 울트라마린·본색·구리색의 제한 팔레트
- 사업자를 카드가 아니라 수집·편집 대상처럼 다루는 구성
- 이미지 확대와 밑줄 이동만 사용하는 절제된 상호작용

### Silly Nice

- 작은 카드 묶음보다 큰 장면과 대담한 비율
- 브랜드와 상업 콘텐츠를 같은 시각 언어로 구성
- 무난한 스타트업 랜딩페이지를 피하는 강한 타이포그래피

## v2에서 제거한 요소

- 녹색 심볼 로고
- 이모지 메뉴 및 이모지 이미지
- 파스텔 그라데이션 영웅 영역
- 녹색 중심 팔레트
- 둥근 카드 반복
- 동일 크기 4열 카드
- 배지·가격·혜택의 과밀 배치
- 설명문이 긴 메뉴 상자
- AI 반짝이·로봇 표현
- 주민 홈의 AI 홍보실 노출
- 사진 대용 무작위 이모지와 임시 그라데이션

## 구현한 상호작용

- 홈 / 목록 / 상세 라우트 전환
- 검색어 입력 후 목록 이동
- 분야별 이동
- 주민 관계 필터
- 분야 필터
- 주민 관계 우선 정렬
- 상세 갤러리 전환
- 찜하기 상태 변경
- 범위 밖 메뉴의 명시적 안내 피드백
- 모바일 하단 내비게이션

## QA

- 1440×1100: 가로 넘침 없음
- 390×844: 가로 넘침 없음
- 모바일 본문 16px, 주요 터치 영역 48px 이상
- JavaScript 예외 0건
- 검색, 필터, 상세 갤러리, 찜 상태 동작 확인
