## 4. v7 Silly Color 미채택

### 상태

`REJECTED_EXPERIMENTAL`

### 보존

- 필요한 일 찾기 Finder
- 서비스 비교
- 지도·목록 전환
- 대표 이웃 선택
- 강한 클릭 피드백
- 색면이 구역을 구분하는 방식

### 미채택 이유

형광 핑크·라임, 두꺼운 검은 테두리, 큰 그림자와 장식이 동시에 적용되어 파일럿 단지의 일상 서비스보다 젊은 캠페인 사이트에 가까웠다.

또한 공개 사이트 감사 문서가 실제 모든 화면의 DOM·CSS·프레임 단위 모션을 직접 확인한 것은 아니므로 원본 충실도 승인자료로 사용할 수 없다.

## 5. v7 파일 중복 확인

`danjion-neighbor-life-v7-silly-color-keyart.html`과 `danjion-neighbor-life-v7-silly-color-system.html`은 SHA256이 동일한 같은 파일이다.

- 둘 다 보존 가능
- 별도 디자인안 두 개로 계산하지 않음
- 이후 인용 시 `keyart` 파일을 대표 파일로 사용
